アイコン新旧照合

FontAwesome Free 5.15.4 の同梱（1.17MB）をやめ、使う42種だけを SVG で埋め込みました。 旧＝FontAwesome 本体が描いたもの、新＝埋め込んだ SVG です。

見かた

  1. 差分列は、細い輪郭だけなら一致です（アンチエイリアスの差）。 形が塗りで浮かび上がったら不一致。 最終行の対照が「本物の不一致」の見本です。
  2. 逆の地列は、この頁と反対の地色で描いたものです（色は currentColor 追従）。 VSCode のライト／ダーク両テーマで見えるかの確認になります。 OS のテーマを切り替えれば、地色も入れ替わります。
  3. おかしいものがあれば 番号で指摘してください。例：「7 と 23 が違う」
